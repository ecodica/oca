Installation
============

Prerequisites:
==============
- Odoo 17.0 Community Edition

Configuration
=============

Go to Settings > Users & Companies > Groups and activate Debug Mode.
After that, new pages on the Group Form View show up: Allowed Menus and Allowed Actions.
Set the Menus and Actions you would like the user to have access to.

Usage
=====

After a group is configured and created, the user which is assigned the specific group can only see and access the assigned Menus and Actions.
Other Access Rights should still be added to the user for him to be able to execute specific actions necessary.
